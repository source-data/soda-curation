# Life Science Alliance

Apply `common.md` for the report format, statuses, mmQC mapping and every check not restated here.

Where this file restates a check, it overrides `common.md`. Checks that exist only at EMBO Press are `N/A`: B4 (synopsis image), F7 (author checklist and point-by-point response), G11 (Appendix file), C8 (The Paper Explained). Note: "not an LSA requirement".

Run the LSA-only checks in this file (A7, B2, B7) as well as the shared checklist.

## Overrides

#### A1 · Editable, clean manuscript file
- **Wording:** "Please upload your main manuscript text as an editable doc file." / "Please upload a clean manuscript file without the highlighted text. The version with highlighted changes you can upload with the file designation "Related Manuscript File"."

#### A3 · Each figure uploaded as its own file
- **Pass:** Every main and supplementary figure is an individual single-page file (TIFF, EPS, PDF or PowerPoint; ≥300 dpi; max. 17.5 × 22.8 cm). A figure too large for one page is split into two figures.
- **Fails when:** Figures are merged into one PDF. Supplementary figures are only inside an SI file. A figure spans several pages.
- **Wording:** "Please upload all figure files as individual ones, including the supplementary figure files; all figure legends should only appear in the main manuscript file."

#### A4 · Supplementary material packaged correctly
- **Pass:** No combined "Supporting Information" file. Supplementary figures and tables are uploaded separately and individually, with supplementary tables as .xls/.xlsx. No section in the text summarising the supplementary material.
- **Fails when:** A combined SI file, or tables as PDF/images.
- **Wording:** "Please remove the file with supplementary information. Supplementary figures and tables should be uploaded separately and individually."

#### A6 · Movies / videos
- **Pass:** MP4 preferred (MOV/MPG/AVI accepted), ≤10 MB each, max. 10 per manuscript, named Video1.mp4 … in citation order. Every video called out in the text. Video legends stay in the manuscript.
- **Wording:** "Please add callouts for all videos to your main manuscript text." / "Please upload each video as an individual file named in citation order (Video 1, Video 2 …)."

#### A7 · Graphical abstract
- **Applies:** LSA only · **Level:** Required if applicable (the graphical abstract itself is optional)
- **Pass:** If supplied: a single high-resolution file (≥300 dpi; TIFF, JPG or EPS) uploaded with designation "Graphical Abstract", and not inside the manuscript file.
- **Fails when:** Graphical abstract is embedded in the manuscript or uploaded under the wrong designation.
- **Wording:** "Please upload the graphical abstract as a single file with the file designation "Graphical Abstract" and remove it from the manuscript file."

#### B2 · Running title
- **Applies:** LSA only · **Level:** Required
- **Pass:** Running title entered in the system; ≤40 characters including spaces; differs from the full title.
- **Fails when:** The running title is missing, too long, or identical to the title.
- **Wording:** "Please add a Running Title in our system." / "Please include a running title (max. 40 characters) that differs from the potentially longer main title."

#### B3 · Synopsis text / summary blurb
- **Pass:** Summary Blurb / Alternate Abstract entered in the system: one sentence, ≤200 characters including spaces, present tense, third person, no author names. Not part of the manuscript section order.
- **Fails when:** The text is missing or too long, or it names the authors or uses "we".
- **Wording:** "Please add a Summary Blurb/Alternate Abstract in our system."

#### B4 · Synopsis image
- **Status:** `N/A`. Not an LSA requirement.

#### B5 · Keywords
- **Pass:** Up to 6 keywords, in alphabetical order, entered in the system.
- **Wording:** "Please add Keywords for your manuscript in our system."

#### B6 · Subject category
- **Wording:** Combine with B5 as "Please add Keywords and Category for your manuscript in our system."

#### B7 · Social media handles
- **Applies:** LSA only · **Level:** Required
- **Pass:** X and Bluesky handles of the host institute and of at least one author entered in the system.
- **Fails when:** Handles are not entered. Confirm actual presence before passing.
- **Wording:** "Please add the X and Bluesky handles of your host institute/organisation, as well as your own and/or one of the authors, in our system."

#### B10 · Funding entries
- **Pass:** System funding data consistent with the full agency names and grant numbers in the Acknowledgements.

#### C1 · Sections present and in correct order
- **Pass:** Title page → Abstract → Introduction → Results → Discussion → Materials and Methods → Data Availability → Acknowledgements → Author Contributions → Conflict of Interest → References → Figure legends (main and supplementary) → Tables and table legends.
- **Wording:** "Please consult our manuscript preparation guidelines https://www.life-science-alliance.org/manuscript-prep and make sure your manuscript sections are in the correct order."

#### C3 · Abstract
- **Pass:** As in the common guideline, and the text is identical in the system.
- **Wording:** Add "Please update the system as well to match the manuscript file."

#### C5 · Discussion
- **Level:** Required
- **Pass:** A single Discussion section. Any Conclusion is merged into it, and it has no subheadings.
- **Fails when:** A separate "Conclusion(s)" section exists or the Discussion has subheadings.
- **Wording:** "Please incorporate any points from the Conclusion section into the Discussion; we only allow a Discussion section." / "Please remove the sub-headings from the Discussion."

#### C7 · Methods heading
- **Pass:** Headed "Materials and Methods".
- **Wording:** "Please title this section 'Materials and Methods'."

#### C8 · The Paper Explained
- **Status:** `N/A`. Not an LSA requirement.

#### D1 · Author contributions
- **Pass:** An Author Contributions section is present in the manuscript and in the system, covering every author (CRediT nomenclature encouraged).
- **Fails when:** It is missing from the manuscript or omits authors.
- **Wording:** "Please add an Author Contributions section to your main manuscript text and the system, and be sure that all authors are mentioned."

#### D2 · Contributions qualify for authorship
- **Pass:** Each author's contributions in the system and in the manuscript Author Contributions section meet authorship criteria.
- **Wording:** Keep the common wording, including "and in the Author Contributions section of the manuscript".

#### D3 · Competing interests statement
- **Pass:** Headed "Conflict of Interest", after Author Contributions.
- **Fails when:** Missing, wrongly named ("Disclosure and Competing Interests Statement", "Competing interests", "Ethics declarations", "Author Declaration"), or in the wrong place.
- **Wording:** "Please add a Conflict of Interest statement to your main manuscript text." / "Please rename "[CURRENT HEADING]" to "Conflict of Interest.""

#### D5 · Animal ethics statement
- **Wording:** Add "in accordance with LSA's guidelines (https://www.life-science-alliance.org/editorial-policies#animals)."

#### D7 · BioRender / AI-assisted graphics
- **Pass:** The acknowledgement names the specific figure panels created with BioRender and, where applicable, states that BioRender uses an integrated AI-assisted design model.
- **Fails when:** A generic acknowledgement names no panels.
- **Wording:** "When acknowledging the use of BioRender for the preparation of figures, please refer to the specific image panels and, if applicable, kindly indicate that BioRender utilises an integrated AI-assisted design model."

#### E1 · Data Availability section named and placed
- **Pass:** A single section headed exactly "Data Availability", placed after Materials and Methods.
- **Wording:** "The "Data Availability" section should be placed after the Materials & Methods section. Please consult our guidelines at https://www.life-science-alliance.org/manuscript-prep#format" / "Please rename "[CURRENT HEADING]" to "Data Availability.""

#### E2 · Datasets deposited
- **Wording, when data are not yet deposited:** "We strongly encourage you to deposit your [DATASET] to a recommended repository and include the name and accession ID in the section titled 'Data Availability'."

#### E4 · Source data
- **Level:** Recommended, except the Data Availability statement when source data are provided (that statement is required).
- **Pass:** Source data are encouraged: one file per main figure (e.g. `SourceDataForFigure1A-F.pdf`) with uncropped blots and numerical values, uploaded as "figure source data". If provided, their availability is stated in the Data Availability section (`ACTION` if missing) and they are referred to in the manuscript (`ADVISE` if missing). Raw data presented as a supplementary figure is better supplied as source data (`ADVISE`).
- **Fails when:** Source data are provided but not mentioned in the Data Availability section.
- **Wording:** "Please explicitly state the availability of source data for the manuscript in the 'Data Availability' statement." / "Thank you for providing the underlying source data. We recommend that you refer to source data files in the manuscript." / *(none provided)* "We encourage you to provide source data (one file per main figure, with uncropped blots and numerical values)."

#### E5 · Data and resources cited
- The EMBO Press `[DATASET]` tag and "Data ref:" citation form are not required.

#### E6 · No "data not shown"
- **Pass:** Neither "data not shown", "manuscript in preparation" nor "manuscript submitted" appears anywhere. "Unpublished observations" is not a substitute: the data are provided or the claim is removed.
- **Wording:** "LSA does not permit citation of "data not shown," "manuscript in preparation," "manuscript submitted," etc., in any section of the manuscript. Please provide evidence to back the statement on page [X]. If you cannot provide the evidence to back the claim, please remove it."

#### F5 · Reagents and resources table
- **Pass:** A materials/reagents table (if provided) is referred to at the start of the Methods. Buffer compositions (with pH) are given in a reagents and solutions section. All primers are listed, including those for reference/housekeeping genes.
- **Fails when:** The table is not referenced, buffers lack pH, or reference-gene primers are missing.
- **Wording:** "Thank you for providing a detailed list of all used materials. We encourage you to make a general reference to this table at the start of the methods section." / "Please provide buffer compositions including pH, and include primers for reference/housekeeping genes."

#### F7 · Author checklist and point-by-point response
- **Status:** `N/A`. Not an LSA requirement.

#### G3 · Legends placed correctly
- **Pass:** Main figure, supplementary figure and table legends are all in the manuscript file after the References.
- **Wording:** "Please add your main, supplementary figure, and table legends to the main manuscript text after the references section."

#### G10 · Supplementary nomenclature
- **Pass:** "Figure S1…", "Table S1…", "Video 1…".
- **Wording:** "Please name supplementary items consistently (Figure S1, Table S1, Video 1) in file names, callouts and legends."

#### G11 · Appendix file
- **Status:** `N/A`. Not an LSA requirement.

#### H1 · Reference format
- **Pass:** The first 10 authors are listed, then "et al."; journal names are abbreviated and italic. Citations in the text are author–year or numbered.
